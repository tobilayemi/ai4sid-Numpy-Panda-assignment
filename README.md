# 📊  NumPy & Pandas Market Data Analysis Assignment

This repository contains my submission for a data analysis assignment focused on applying NumPy and Pandas to simulate, clean, transform, and analyze real world datasets.

The project uses Nigerian market price data to demonstrate data preprocessing, exploratory analysis, feature engineering, and dataset integration.

# 🎯  Objectives

The assignment aimed to:

Apply NumPy for numerical simulation and aggregation

Use Pandas for data cleaning, transformation, and exploration

Perform domain specific analysis using market price data

Demonstrate data integration through a dataset merge bonus challenge

# 🧹  Key Data Processing Steps

The workflow included:

- Cleaning column names and standardizing text fields

- Converting price values from text to numeric

- Handling missing and unrealistic values

- Standardizing date formats

- Feature engineering (price ranking within states)

- Dataset merging for enhanced analysis
